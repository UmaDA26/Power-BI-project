# Real-Time AQI Trends and Pollution Analysis

## 📌 Project Overview

This project analyzes **Air Quality Index (AQI) data** across India to understand air quality conditions, identify pollution patterns, and compare AQI levels across states, cities, and pollutants.

The project focuses on transforming raw air-quality data into meaningful insights using **Excel and Power BI**, followed by interactive visualization through a dashboard.

## 🎯 Objectives

* Analyze AQI levels across different states, cities, and monitoring stations.
* Identify locations with different levels of air quality.
* Analyze pollutant-wise variations and their contribution to air quality conditions.
* Identify trends and patterns in AQI data.
* Categorize locations based on AQI levels.
* Present the findings through an interactive Power BI dashboard.

## 🛠️ Tools & Technologies

* **Microsoft Excel** – Data cleaning and initial data preparation
* **Power Query** – Data transformation and preprocessing
* **Power BI** – Data modeling, analysis, and dashboard development
* **DAX** – Calculated columns and measures
* **GitHub** – Project documentation and version management

## 🔄 Project Workflow

### 1. Data Collection

Collected the AQI dataset containing location-wise and pollutant-wise air-quality information.

### 2. Data Cleaning

Used **Excel and Power Query** to prepare the dataset by:

* Handling missing values
* Checking inconsistent values
* Removing unnecessary data
* Standardizing data formats
* Preparing date-related fields
* Checking pollutant and AQI values

### 3. Data Transformation

Transformed the cleaned dataset into an analysis-ready format using Power Query and created the required calculated fields and measures using DAX.

### 4. Data Analysis

Performed analysis to understand:

* AQI levels by state and city
* AQI categories across locations
* Pollutant-wise patterns
* State-level air-quality differences
* Geographic distribution of AQI
* Variations in pollutant measurements

### 5. Dashboard Development

Developed an interactive **Power BI dashboard** with two major analytical views:

**Location-wise Analysis**

* KPI cards
* State-wise AQI comparison
* City/location analysis
* AQI category distribution
* Geographic visualization
* Interactive slicers

**Pollutant-wise Analysis**

* Pollutant comparison
* Pollutant-level trends
* AQI and pollutant analysis
* Interactive filtering

## 📈 Key Insights

The analysis helps identify:

* Locations with relatively better and poorer AQI conditions.
* Differences in air quality across states and cities.
* Pollutants associated with variations in air quality.
* Distribution of locations across different AQI categories.
* Geographic patterns in air-quality conditions.
